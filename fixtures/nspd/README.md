# Публичные контрольные ответы

Источник: публичная карта https://nspd.gov.ru/map?thematic=PKK, наблюдение 29.09.2026.

Каталог сокращён до названий, типов и идентификаторов слоёв. Ответ пространственного запроса содержит пять реальных полигонов и публичные характеристики; служебные поля удалены. Cookies, токены, заголовки и личные заявки не включены. Хеш сокращённой фикстуры отличается от хеша исходного ответа.

Данные используются для воспроизводимой проверки CRS, отображения и отказа от вывода о полноте. Они не являются полной кадастровой выгрузкой и не доказывают доступность земли.
