# НСПД: результаты диагностики 29 сентября 2026

> Обновление этапа 3: тайм-аут пространственного клиента устранён для пилотных проверок переходом на HTTP/2. Ниже сохранена исходная диагностика HTTP/1.1. Актуальный результат — в PROJECT_STATUS.md, раздел «Этап 3».

## Подтверждено

- Chrome с открытой пользователем сессией получает каталог `GET /api/geoportal/v1/layers-theme-tree?themeId=1`: HTTP 200, 63 слоя. Публичный ответ сохранён в `data/nspd_capture/2026-09-29/layers-catalog.json`.
- Публичный поиск `GET /api/geoportal/v2/search/geoportal?thematicSearchId=1&query=90%3A12%3A172101%3A420` работает также из Python без переноса cookies или токенов браузера. Повторная проверка нового клиента: 1,26 секунды, один объект; затем успешная проверка через интерфейс приложения.
- Выделение небольшого контура в Chrome вызвало `POST /api/geoportal/v1/intersects?typeIntersect=fullObject`. Ответ HTTP 200, пять участков; все пять показаны также в интерфейсе НСПД. Тело запроса и публичный ответ сохранены отдельно, без заголовков сессии.
- Исходная полигональная геометрия явно содержит EPSG:3857; приложение преобразует её в WGS84. Неизвестная CRS отклоняется.
- Контрольный участок 90:12:172101:420 имеет указание федеральной собственности и автомобильного транспорта. Пять объектов контрольного контура также нельзя считать свободными кандидатами.

## Не решено

- Прямой пространственный POST из Python обрывается или не завершает ответ. Повторная проверка нового клиента: тайм-аут через 25,29 секунды. Смена VPN не выполнялась; причина на уровне маршрута/сервиса не установлена.
- Прямое чтение каталога также давало тайм-аут, поэтому используется датированный каталог, реально полученный через Chrome.
- В ответе пространственного поиска отсутствуют подтверждённые сведения о полном количестве результатов и пагинации. Пять объектов не доказывают полноту кадастрового покрытия. `complete` всегда false.
- Слои свободных от прав третьих лиц и аукционов присутствуют в каталоге. Их идентификаторы программа разрешает по названиям из каталога; успешная прямая выборка этих слоёв пока не подтверждена.
- Официальная граница села, полный кадастр территории, ПЗЗ/ЗОУИТ для всей области и юридически проверенные кандидаты не получены. Автоматический поиск всей свободной земли и полный пилот ТЗ не завершены.

## Что добавлено

Открыть `http://127.0.0.1:8765/nspd.html` или пункт «Живой поиск НСПД» в основном приложении.

1. Поиск по кадастровому номеру с реальным ответом НСПД.
2. Ограниченный поиск по прямоугольнику (до 10 км² в проекции карты), готовый к использованию при доступном POST. Один запрос без повторов; запросы сериализованы.
3. Кнопка сохранённого снимка Chrome: пять реальных объектов, явная дата и пометка снимка.
4. Карта геометрии, права/собственность и вид использования из ответа источника.
5. Экспорт GeoJSON с источником, датой, запросом, хешем ответа и предупреждением о неполноте.
6. Отдельный сохраняемый список «В разработке». Он не заменяет проверенные GIS-кандидаты и не архивирует их.
7. Ошибка связи сохраняет предыдущие результаты и показывает, что они не обновлены.

Проверка: 35 автоматических тестов; Chrome — загрузка снимка и успешный живой поиск контрольного номера. Заявления, регистрация и участие в торгах не выполнялись.

## Следующий технический этап

Установить устойчивый поддерживаемый канал пространственной выгрузки: проверить доступность POST в той же сети без изменения защиты, выяснить ограничения сервиса и доступный официальный экспорт. Получить подтверждение полноты и границу пилотной территории, затем подключить пространственный расчёт окон. Пока допустимы исследования конкретных объектов и работа с датированными наблюдениями.
