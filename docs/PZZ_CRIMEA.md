# Региональный источник ПЗЗ Крыма

В проект подключён опубликованный слой **«Территориальные зоны ПЗЗ»** [общей карты РГИС Крыма](https://rgis.rk.gov.ru/map/Map.aspx#/maps/34f88ad7-6208-4f45-b29a-daabbb7119fe). Это отдельный источник, отличающийся от ранее подключённого генплана 2019 года.

**Полная действующая карта пока не получена.** Проверка 08.10.2026 показала:

- официальный каталог карты и описание слоя доступны; идентификаторы и параметры взяты из опубликованных метаданных;
- WFS `GetFeature` для пилотной области вернул HTTP 200 и 0 объектов; такой же результат получен через кнопку приложения в 21:17:36 МСК;
- WFS `GetFeature resultType=hits` без пространственного фильтра в 21:09:58 МСК вернул общее количество 0;
- WMS по объявленной рамке Крыма в 21:13:06 МСК вернул полностью прозрачное изображение 512×512;
- [публичная ГИСОГД Крыма](https://public.gisogd.rk.gov.ru/) в 21:10:56 МСК завершила соединение ошибкой TLS до HTTP-ответа.

Эти наблюдения характеризуют проверенные публичные сервисы. Они не означают, что в Крыму нет утверждённых ПЗЗ. Объявленная рамка слоя также не подтверждает фактическое покрытие.

## Как использовать

1. Откройте [основной поиск](http://127.0.0.1:8765/nspd.html) и выделите область двумя углами.
2. Нажмите **«Получить зоны ПЗЗ Крыма для области»**. Приложение сохраняет дату, область запроса, исходный ответ и SHA-256.
3. Пересчитайте контуры кнопкой **«Найти контуры»**. Для пересчёта уже полученного кадастра можно отключить обновления НСПД и торгов.
4. Галочка **«Показать региональные ПЗЗ»** включает полученную геометрию. Пересечения кандидата с зонами попадут в карточку, досье и GeoJSON.

При нынешнем пустом ответе статус прямо сообщает **«Источник подключён, зоны не получены»**. Другая область не применяется к расчёту. Ошибка нового запроса сохраняет прежний датированный результат. Получение ПЗЗ требует отдельного нажатия и не запускается при открытии страницы или изменении области.

Рабочий запрос ограничен выбранной областью до 10 км² в проекции карты, 1000 объектами и 5 МБ. Достигнутый предел, несовпадающая система координат, неполные счётчики или продолжение ответа отклоняются. Весь Крым не скачивается одним запросом. Признаки полноты покрытия и действующей редакции остаются неподтверждёнными.

Коды и названия зон сохраняются из источника без догадок. Пересечение с зоной само по себе не подтверждает допустимость ИЖС. До получения регламентов и проверки действующей редакции слой не меняет подбор контуров и правовые отметки.

## Опубликованные параметры

| Параметр | Значение |
|---|---|
| Карта | `34f88ad7-6208-4f45-b29a-daabbb7119fe`, «Общая карта» |
| Слой | `8d18d817-1aa5-4d55-8afc-d7a93a19a4c7`, «Территориальные зоны ПЗЗ» |
| WFS | `https://rgis.rk.gov.ru/geoserver/wfs`, версия 1.1.0 |
| Тип объектов | `rgis:territorialzone_polygon` |
| Поля | `symbol`, `territorialzonename`, `territory`, `status`, `dataobjectkey` |
| Запрашиваемая CRS | EPSG:3857; сохранённая геометрия EPSG:4326 |
| Заявленная исходная CRS | EPSG:19635; точность исходных границ не установлена |

Метаданные карты получены 08.10.2026 в 21:11:33 МСК, SHA-256 `bcd3a4a480b4180bbdafd3ab9df7c224911e02cd054f4f7b007fea233f8c380c`. В метаданных отсутствуют даты редактирования и реквизиты утверждающего акта. Диагностика сохранена локально в `data/stage50`, рабочий источник — в `data/pzz`; исходные ответы не отправляются в GitHub.

API приложения: `GET /api/pzz`, `GET /api/pzz/export`, защищённый локальным токеном `POST /api/pzz` с областью. Расчёт версии 12 учитывает идентификатор этого источника; после обновления прежний расчёт становится устаревшим.

## Что требуется для полного покрытия

Нужны непустые официальные данные зон, проверенное покрытие выбранной территории, действующая редакция карты и связанные с ней регламенты. При отсутствии заполненного публичного сервиса потребуется официальная выгрузка либо материалы муниципальных образований с проверенной геопривязкой. Фрагменты изменений Трудовского поселения и функциональные зоны генплана эту задачу не закрывают.

Рабочее подключение источника завершено; получение полной действующей карты остаётся открытой задачей.
