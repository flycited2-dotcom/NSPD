# Сохранённые ответы поиска НСПД

Если кадастровая карта работает в авторизованном браузере, а прямой запрос приложения возвращает 403, полученные браузером ответы можно использовать отдельно. Это импорт датированного снимка; он не восстанавливает прямое подключение приложения и не подтверждает сегодняшние права или условия лота.

В разделе «Земельные публикации по всему Крыму» раскройте «Загрузить сохранённые ответы НСПД», выберите подготовленный JSON-файл и нажмите «Сопоставить ответы с лотами». После успешного импорта пересчитайте основной поиск, отключив ненужные сетевые обновления. Импорт выполняется локально, без запросов к НСПД. Результат подходит для той же выбранной области; после изменения области требуется новое сопоставление.

Файл содержит от одного до пяти успешных ответов:

```json
{
  "version": 1,
  "observations": [
    {
      "url": "https://nspd.gov.ru/api/geoportal/v2/search/geoportal?thematicSearchId=1&query=90%3A12%3A132401%3A5042",
      "status": 200,
      "received_at": "2026-10-08T10:35:00+00:00",
      "sha256": "SHA-256 точного UTF-8 текста ответа",
      "body": "Точный JSON-текст ответа НСПД с data и meta"
    }
  ]
}
```

Значения `body` и `sha256` в примере — описания полей. При подготовке файла `body` должен содержать исходный текст ответа, включая пробелы; SHA вычисляется от этих точных UTF-8 байтов. Повторная сериализация ответа меняет хеш. Дата получения указывается с часовым поясом; отклонение в будущее более пяти минут не допускается. Дата импорта записывается отдельно. Сырые ответы и метаданные сохраняются локально в `data/nspd_browser`, экспорты содержат нормализованную геометрию, источник, даты и SHA.

Поддержан наблюдавшийся ответ поиска одного участка: `data.type=FeatureCollection`, ровно один объект категории ЕГРН 36368 и `meta=[{"totalCount":1,"categoryId":36368}]`. Структурированный `options.cad_num` должен совпадать с запросом и номером сохранённого лота. URL допускает только опубликованный endpoint и два указанных параметра. Проверяются согласованная явная EPSG:3857/4326, замкнутые двумерные кольца, конечные координаты и валидный Polygon/MultiPolygon; автоматического исправления границ нет.

Импорт не принимает HAR, заголовки или сведения авторизации. Размер одного исходного ответа — до 1 МБ, файла порции в интерфейсе — до 10 МБ. Ошибка любого ответа отменяет всю порцию. Непустая ранее полученная геометрия не заменяется; смена каталога или обследования во время операции отменяет запись. Файлы с ответами 403/404 и неполными данными не импортируются как границы и не означают расположение лота вне области.

Формат файла сам по себе не удостоверяет источник и дату. Для принятого ответа сохраняется `provenance_verified=false`; проверка подлинности остаётся отдельной задачей. `geometry_confirmed` и признаки прав/готовности к подаче не устанавливаются. Ошибка прежнего прямого запроса остаётся в журнале; даты поиска торгов и страниц не обновляются датой импорта. Реальный пилот 08.10.2026 получен обычным поиском в Chrome и сетевым наблюдением ответа без копирования cookies или headers.
