# Исходные координаты из XML-выписки в ZIP

Обработчик ZIP поддерживает наблюдаемую структуру `extract_about_property_land` без пространств имён. Из XML до 2 МиБ выбираются только кадастровый номер объекта, исходный идентификатор системы координат и контуры XY. Владелец, получатель выписки, адрес и сведения о правах не переносятся в результат. Исходный XML не сохраняется отдельным распакованным файлом; оригинал остаётся внутри полученного ZIP.

Координаты сохраняются в исходном порядке и точном десятичном написании. Разбор не переставляет оси, не сортирует точки, не замыкает и не исправляет контуры. При наличии номеров точек проверяется их порядок. Последний номер может повторять первый только при точном совпадении исходных координат замыкания. Невалидные контуры перечисляются отдельно; повреждённая/неподдерживаемая структура отклоняется. DTD, сущности, внешние ресурсы, атрибуты и неподдержанные кодировки запрещены. Лимиты: 20 000 узлов, глубина 64, 100 контуров и 5 000 точек.

В отчёте ZIP раскройте «XML ЕГРН: выбранные поля». Показаны SHA, дата получения архива, дата чтения, принятые/пропущенные части и до 100 исходных точек. Экспорт ZIP содержит полный ограниченный набор выбранных координат. В досье кандидата попадают только датированные метаданные, счётчики и неподтверждённая подсказка номера; сырые координаты и строки системы координат туда не копируются.

Для обновления ранее прочитанного ZIP используется проверенный сохранённый исходник. Очередь помечает прежний обработчик как `pending_cached`; кнопка «Прочитать 1 ZIP» перечитывает один такой архив без HTTP. Отсутствующий или повреждённый кэш даёт ошибку без подмены источника новым скачиванием. Явный вызов `reprocess_cached=true` требует точного ключа файла. Старые наблюдения, квитанции и их SHA сохраняются. Каждый безопасный JSON с выбранными полями имеет собственный адрес по SHA содержимого.

Чтение всегда частичное: выбранные поля не означают чтения всей выписки, проверки подписи или актуальности прав. Исходные XY и SKid не устанавливают WGS84/EPSG. Координаты не добавляются на географическую карту и не участвуют в исключении земли до отдельного подтверждения системы координат и принадлежности схемы лоту. Чтение XML не подтверждает свободность участка.
