# Сохранённые RTF торгов

Локальное повторное чтение поддерживает три дополнительных точных управляющих слова: `clftsWidth`, `clwWidth`, `trftsWidth`. Согласно [Microsoft RTF1.9.1, страницы98/101](https://officeprotocoldoc.z19.web.core.windows.net/files/Archive_References/%5BMSFT-RTF%5D.pdf), они задают ширину ячейки/строки или единицы ширины. Обработчик игнорирует форматные размеры и сохраняет последовательность текста ячеек, пустые ячейки и исходные числовые значения.

Список разрешений точечный: регистр остальных команд проверяется строго. Защиты от бинарных блоков, неизвестных управляющих слов с нестандартным регистром, неверных Unicode/кодировок, чрезмерной глубины, размера и объёма текста сохранены. Скрытые назначения и инструкции полей не становятся видимым кадастровым текстом. Версия чтения `torgi-legacy-text-v2`; обработчик DOC по существу не изменён.

Кнопка повторного чтения обрабатывает только подходящий отклонённый RTF текущего каталога, проверяя его сохранённый SHA и связь с текущим поиском. Скачивание не повторяется. Исходный SHA и дата получения остаются прежними; собственная дата повторного чтения записывается отдельно. Неудачное повторное чтение не повторяется бесконечно автоматически.
